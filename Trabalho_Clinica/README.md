# Sistema de Agendamento - Clínica Universitária

**Disciplina:** Linguagem de Programação (DS123)
**Autor:** Mikael Mateus dos Santos Silva

## Descrição
Este sistema gerencia agendamentos de uma clínica universitária e foi estruturado utilizando a linguagem C. A aplicação utiliza Listas Simplesmente Encadeadas para armazenar Pacientes e Listas Encadeadas Dinâmicas com Nó Cabeçalho para o histórico de agendamentos.

## Funcionalidades
- Cadastro de pacientes e de agendamentos (salas, data, hora).
- Listagem por sala e por CPF.
- Remoção de consultas mediante CPF e Data.
- Estrutura altamente modularizada (arquivos .h e .c).

## Como Compilar e Executar
1. Abra o projeto `Clinica.dev` no Embarcadero Dev-C++.
2. Pressione **F11** para compilar e executar o sistema.
